Un solo estilo para todo el ePortfolio

La plantilla es SendIt, montada con Tailwind 4 y Bootstrap Icons. Esta guía fija lo que usamos en todas las páginas. Si necesitas algo que no está aquí, se añade aquí primero y después se usa en el código. Para copiar código, ve al cheat sheet; para buscar una clase, a clases útiles.

Reglas

Solo clases de Tailwind

Nada de style="" ni CSS suelto dentro de las páginas.

Solo colores de la paleta

El lima es para la acción principal de cada bloque. Nunca como color de texto sobre blanco.

Redondeo según el tamaño

rounded-xl en botones, inputs y cards pequeñas; rounded-3xl en cards grandes y secciones; rounded-full en badges.

Reutiliza antes de crear

Mira el cheat sheet antes de escribir clases nuevas. Si falta algo, se añade aquí primero y después se usa.

Botones y enlaces

Un botón primario por bloque. El resto, secundarios. Los tamaños pequeño y grande solo cambian el padding y el texto.

Primario (lima)

Guardar, crear, enviar. Texto negro siempre.

bg-[#cff245]text-blackrounded-xlpx-4 py-2 text-sm font-medium

Secundario

Volver, cancelar, acciones menos importantes. Una versión para fondo claro y otra para oscuro.

border border-gray-300 bg-whiteborder border-gray-700 text-white

Peligro

Solo para borrar o acciones que no se pueden deshacer. Siempre con confirmación.

bg-red-600 text-white hover:bg-red-700

Enlaces

Sobre claro, gris 900 subrayado (no azul). Sobre oscuro, lima sin subrayar hasta el hover.

font-medium text-gray-900 underline underline-offset-4 hover:no-underlinetext-[#cff245] hover:underline

Etiquetas de estado

Una sola variante para toda la web: píldora con anillo. El color depende del estado, nunca del gusto de quien programa la vista.

Estados

Verde: correcto. Amarillo: pendiente o aviso. Rojo: error. Azul: información. Gris: neutro.

inline-flex items-center rounded-full px-2.5 py-0.5 text-xs font-medium ring-1 ring-inset

Tarjetas

Hay dos tamaños. Se apoyan siempre sobre el gris claro y son siempre blancas.

Compacta

Elementos densos que se repiten mucho en una lista.

rounded-xl border border-gray-200 bg-white p-4 shadow-sm

Grande, clicable

Elementos con más contenido. Sube la sombra al pasar el ratón.

rounded-3xl border border-gray-200 bg-white p-8 shadow-sm hover:shadow-md

Detalle

Página de un solo elemento. Datos en lista de definición y los botones abajo.

rounded-3xl border border-gray-200 bg-white p-8 shadow-sm

Formularios y avisos

Campo de texto

Etiqueta arriba, ayuda o error debajo. El foco se marca con anillo lima.

rounded-xl border border-gray-300 bg-white px-4 py-2 text-smfocus:ring-2 focus:ring-[#cff245]

Mensajes

Confirmaciones y errores. Mismo patrón de color que las etiquetas: 50 de fondo, 800 de texto.

rounded-xl border border-green-200 bg-green-50 px-4 py-3 text-sm text-green-800

Escala de espacio

Solo estos pasos en p-, gap- y mt- (8, 16, 24, 32, 48 y 80 px). gap-4 entre elementos, p-8 dentro de una card grande, py-20 entre secciones.

Estructura de una página

Las páginas se componen de bandas que alternan fondo oscuro y claro. Vuestro contenido va en una sección clara.

cabecerapx-8 py-4 bg-[#0d0e11]
sección oscurapx-8 py-20 bg-[#0d0e11]
sección clarabg-[#f6f7fa] rounded-3xl
vuestra páginamx-auto max-w-5xl
sección oscurapx-8 py-20
piepx-8 py-20

Qué recordar

Las secciones alternan negro y gris claro. Cada una usa px-8 py-20 y un contenedor mx-auto con ancho máximo.

Dentro de vuestra página: max-w-4xl para listados, max-w-3xl para detalle y max-w-2xl para formularios.
